6. Secure Ownership Immediately

The Facebook Page should never depend on only one person.

Elisha — Primary full control

Elisha should remain the original creator and primary full-control administrator through her personal Facebook account.

Otha — Second full-control administrator

After the Page is successfully created and stable, add Otha if he wants through his real personal Facebook account.*Unless this was the one you had blocked. In that case that may flag a review and it would be best that Otha stays the Primary

Otha then has full control and can share permissions as you decide together with who and what for.

Each person should access the Page through their own real Facebook account.

Contractors, agents, and social-media operators

Contractors and social-media operators should receive task access through Meta Business Suite whenever possible.

They should not automatically receive full control.

Full-control users may be able to:

  • Change Page settings
  • Add or remove administrators
  • Remove the original owner
  • Delete the Page
  • Change security and access

Reserve full control for trusted founders or permanent organizational leadership.

11. If Facebook Blocks or Challenges the Setup

Stop repeating the same attempt.

Do not

  • Create several personal Facebook profiles
  • Use a fake name
  • Use someone else’s identity
  • Rotate through several new email addresses
  • Create several duplicate nonprofit Pages
  • Share one Facebook password among several people
  • Submit the same failed Page request repeatedly
  • Use the recently blocked email as the personal account recovery email
  • Make rapid changes from several devices or locations

Do

  • Use the official Facebook appeal or verification process
  • Complete verification through Elisha’s established personal account
  • Save screenshots of every error
  • Record the date and time
  • Record the device and browser used
  • Save any Facebook case number
  • Copy the exact error message
  • Stop after the first failed repeat attempt
  • Report the issue before changing accounts, emails, or ownership

Information to save if blocked

  • Exact Facebook error message
  • Screenshot
  • Date
  • Time
  • Account used
  • Email connected to the account
  • Phone number connected to the account
  • Browser or app used
  • Whether a VPN was active
  • Page name entered
  • Username entered
  • Category selected
  • Any verification requested
  • Facebook case number
